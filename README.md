## Sobre los proyectos de trabajo

Los proyectos desarrollados en empresas se publican en **versión sanitizada**: sin credenciales, dominios, datos de clientes ni nombres reales, y con la marca reemplazada. Cada uno incluye el script que usé para limpiarlo y verificar que no queden fugas antes de publicar.
